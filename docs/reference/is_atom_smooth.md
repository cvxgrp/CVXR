# Check if an Atom is Smooth

Atom-level hook (default FALSE); smooth atoms (e.g. trig/hyperbolic)
override this to TRUE. Mirrors CVXPY's `Atom.is_atom_smooth()`.

## Usage

``` r
is_atom_smooth(x, ...)
```

## Arguments

- x:

  An atom object.

- ...:

  Not used.

## Value

Logical scalar.
