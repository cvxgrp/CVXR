# Check if an Expression is Smooth

Smooth = constant, or both linearizable-convex and linearizable-concave.
Mirrors CVXPY's `Expression.is_smooth()`.

## Usage

``` r
is_smooth(x, ...)
```

## Arguments

- x:

  An expression object.

- ...:

  Not used.

## Value

Logical scalar.
