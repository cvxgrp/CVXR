# Check if a Leaf is Diagonal

Reports the `diag` attribute of a Variable or Parameter, as CVXPY's
`Leaf.is_diag()`. Defined for leaves only.

## Usage

``` r
is_diag(x, ...)
```

## Arguments

- x:

  A Variable or Parameter.

- ...:

  Not used.

## Value

Logical scalar: `TRUE` if `x` was created with `diag = TRUE`.
