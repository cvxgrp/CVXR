# Total variation (deprecated alias)

**\[deprecated\]**

## Usage

``` r
tv(...)
```

## Arguments

- ...:

  Arguments passed to
  [`total_variation()`](https://www.cvxgrp.org/CVXR/reference/total_variation.md).

## Value

The expression returned by
[`total_variation()`](https://www.cvxgrp.org/CVXR/reference/total_variation.md):
the total variation of the argument(s). A deprecation warning is issued
once per session.

## Details

Use
[`total_variation()`](https://www.cvxgrp.org/CVXR/reference/total_variation.md)
instead.
