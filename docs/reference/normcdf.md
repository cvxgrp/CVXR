# Standard Normal Cumulative Distribution Function

Elementwise standard normal CDF \\\Phi(x)\\. A smooth (DNLP) atom: it is
neither convex nor concave, so it is usable only on the
disciplined-nonlinear- programming path.

## Usage

``` r
normcdf(x)
```

## Arguments

- x:

  An Expression.

## Value

A Normcdf atom.
