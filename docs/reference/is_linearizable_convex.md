# Check if an Expression is Linearizable-Convex

Convex after linearizing all smooth subexpressions (DNLP composition
rule). Mirrors CVXPY's `Expression.is_linearizable_convex()`.

## Usage

``` r
is_linearizable_convex(x, ...)
```

## Arguments

- x:

  An expression object.

- ...:

  Not used.

## Value

Logical scalar.
